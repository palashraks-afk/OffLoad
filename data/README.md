# data/

Public data and results used by the project.

- `raw/` downloads (large files are git-ignored; commands to re-fetch are in [`../shiftready/README.md`](../shiftready/README.md)).
- `processed/` derived tables. Crash tables here are used by Shift Ready; hospital and offload files belong to the archived OffloadWatch project.
- `research/` crash and health-death tables for CA-23 and CA-33 (public FARS and state data).
- `config/` settings and a hospital crosswalk (OffloadWatch).
