# Screen recording on the MacBook: steps and timestamps

Use this next to the script in `VIDEO_SCRIPT.md`. Times are estimates; time one rehearsal. The video must be under 3:00.

## Before you press record (5 minutes)
1. Plug in the charger. Turn on Do Not Disturb. Close other apps. Quiet room, door closed.
2. Open the app in a phone-sized window (Terminal):
```
open -na "Google Chrome" --args --app=https://palashraks-afk.github.io/ShiftReady/ --window-size=420,860
```
3. Run the Night shift example once so you know where everything is. Then reload so you start on the first screen.
4. System Settings, Privacy and Security: allow Screen Recording and Microphone for QuickTime Player and iMovie.
5. Read the script out loud once without recording.

## How to record
1. Press **Cmd + Shift + 5**.
2. Click **Record Selected Portion** and drag the box around the app window.
3. Click **Options**. Microphone: choose "MacBook Pro Microphone" for a one-take video with voice, or "None" if you will add your voice later in iMovie. Save to: Desktop.
4. Click **Record**. Wait 2 seconds, then start.
5. To stop: click the stop button in the menu bar (top right), or press **Cmd + Control + Esc**.
6. The file appears on the Desktop. Play it back and check it.

## What to do on screen, with timestamps
Pause 1 second after every tap so viewers can see what changed.

| Time | On screen |
|---|---|
| 0:00 | Stay on the first screen (dark banner with 0%). |
| 0:08 | Stay on the same screen. |
| 0:22 | Point the cursor at the 0% and the 11 PM tick. |
| 0:59 | Point at the From, To and time boxes. |
| 1:20 | Tap the **Night shift** example. Let the result show. |
| 1:38 | Scroll down. Tap **Message my boss**, then **Ask for better service**. |
| 1:45 | Tap **Early hospital shift**. Set 5:00 AM, **Check my trip** (No). Set 8:00 AM, **Check my trip** (Yes). Switch to **Spanish**. |
| 1:55 | Open **Map**. Drag the slider to 11 PM. Then tap **Employers**. |
| 2:04 | Go back to the first screen. |
| 2:27 | Stay on the 0% and 11 PM screen to the end. |
| about 2:55 | Stop recording. Must be under 3:00. |

## Then
- **Voice added later (recommended):** open iMovie, Create New, Movie. Drag the recording in. Click the microphone icon, pick the MacBook microphone, and read the script while the video plays. If you flub a sentence, move the playhead back, delete that voice part, and record it again. Trim the end. File, Share, File, 1080p, High.
- **One take with voice:** if you recorded with the microphone on and it sounds good, you are done.
- Upload to YouTube as **Public** (not Unlisted), "No" to made for kids. Open the link in a private window to check the sound.
