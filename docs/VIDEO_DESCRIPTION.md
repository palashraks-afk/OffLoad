Title: Shift Ready, Congressional App Challenge 2026

---

Shift Ready is a free web app (English and Spanish, works on phones) that checks whether a worker can get to a shift and back home by bus or train, and helps workers, managers and cities ask for better service when they can't.

Built by Palash Rakshit, Redlands High School, for the 2026 Congressional App Challenge, California's 23rd District.

WHO IT IS FOR
- Workers: check the real timetable for your start time and the ride home after your shift ends. See the last bus, a backup time, and a one-tap note you can send your boss.
- Employers and managers: the Employers tab shows which shift start times your workers can reach by bus or train, so you can see where a small change in start time could help.
- Cities and transit staff: see where service disappears hour by hour on the map, and get a ready-to-send request for better service that cites the numbers.

TRY IT: https://palashraks-afk.github.io/ShiftReady/
CODE AND HOW IT WORKS: https://github.com/palashraks-afk/ShiftReady

BUILT WITH: JavaScript and Python, public bus and train timetables, Census data, crash data and OpenStreetMap.

AI DISCLOSURE: I used an AI tool, Claude Code, and it wrote most of the current code. The idea, the plan, the data and the decisions are mine. Every session is logged publicly: https://github.com/palashraks-afk/ShiftReady/blob/main/docs/AI_USE_LOG.md

Timetable data can be out of date and buses can run late. Check live alerts before you leave. Nothing is sent for you; you send any message yourself.
